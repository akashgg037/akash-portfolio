# Akash Gupta - Developer Portfolio Website

A modern, responsive portfolio website created for **Akash Gupta** (Flutter & Mobile Application Developer, IoT Integrator & QA Lead).

## 🚀 Live Preview Locally
You can open `index.html` directly in any web browser, or launch a quick local development server:

```bash
# Using Python 3
python3 -m http.server 8000

# Open in browser: http://localhost:8000
```

## 📂 Project Structure
```
portfolio/
├── index.html               # Main semantic HTML5 webpage
├── style.css                # Dark mode tech aesthetic & responsive layout
├── script.js                # Interactive filtering, typewriter animation, form handling
├── Akash_Gupta_Resume.pdf   # Direct download copy of resume
└── README.md                # Project documentation
```

## 🛠️ Features
- **Hero Section**: Dynamic typewriter role rotating, quick action buttons, social links, and code card preview.
- **Quick Metrics**: 4+ years experience, 10+ delivered projects, IoT hardware connectivity, full-cycle dev + QA.
- **About Me**: Professional summary, background at Dream Filler Software Solutions, and core strengths.
- **Interactive Technical Skills**: Categorized into Mobile & Frontend, IoT & Connectivity, Integrations & APIs, and Cloud/DevOps.
- **Filtered Project Showcase**: Interactive tabs for *Flutter*, *IoT & Hardware*, *FlutterFlow*, and *QA & Cloud*:
  - *IoT BLDC Fan (BLE, Wi-Fi, MQTT, Alexa/Google Home)*
  - *School Management Platform (RBAC, dynamic scheduling)*
  - *Core Desk Collaboration & Analytics*
  - *Employee Management & Geo-Fencing Attendance*
  - *Local Partner E-Commerce & Rental Platform*
  - *Lottery Management & Pooling Platform*
  - *Broan-NuTone / Watkins Wellness IoT QA & AWS Server Migration*
- **Career Timeline**: Work history with key achievements and tech stack tags.
- **Contact & Direct Messaging**: Email, phone, LinkedIn links, and interactive contact form with mailto fallback and toast notifications.
- **Resume Download**: One-click download linking directly to `Akash_Gupta_Resume.pdf`.

## 🌐 Free Deployment Options
- **GitHub Pages**: Push this directory to a GitHub repository and turn on Pages under Repository Settings -> Pages.
- **Vercel / Netlify**: Drag-and-drop or connect the repository for instant deployment with SSL.
